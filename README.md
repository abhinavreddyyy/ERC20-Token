# ERC20 TOKENS
Developed 2 types of token namely a Manual Token and Our Token.

## Manual Token
Included all the basic functions like name, total Supply, balance of and transfer, to create an ERC20 Token.

## Our Token
Using the OpenZeppelin contracts, I have imported the ERC20 contract which has a pre-written variables, functions to build my own personalized token.
Have also deployed and written few tests for the contract
